# 知识闭环

知识类型：

```text
account / topic / pattern / review / action / experiment / recommendation
```

生命周期：

```text
新事实 → 结构特征 → 与历史比较 → experimental
→ 后续验证 → active → strong
                 ↓
             deprecated
```

任务前优先检索：同账号、同主题、同结构、最近 7–30 天、active/strong Pattern、最近失败 Review。

知识库不是日志，只存以后能直接用于决策的内容。
